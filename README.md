# Password Validator

A lightweight, client-side JavaScript utility designed to validate password strength in real-time. This project ensures user credentials meet modern security standards and criteria before submission.

##  Features

* **Real-time Complexity Validation:** Instantly checks passwords against strict security criteria.
* **Requirement Tracking:** Confirms the presence of:
  * Minimum length requirements (e.g., 8+ characters)
  * Uppercase and lowercase letters
  * Numeric digits (0-9)
  * Special characters (e.g., !, @, #, $, etc.)
* **Visual Strength Indicator:** Dynamic feedback indicating whether a password is weak, medium, or strong.

##  Getting Started

Follow these steps to set up and explore the validator locally.

### Prerequisites
You only need a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari) to run this project.

###  Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**
   ```bash
   cd Email_automation
   ```

3. **Run the project:**
   * Open `index.html` directly in your web browser, or
   * Launch it using the **Live Server** extension in Visual Studio Code.

##  Built With

* **HTML5** - Structure for the password input form and criteria checklists.
* **CSS3** - Visual formatting and dynamic feedback colors (Red/Yellow/Green strength states).
* **JavaScript (ES6)** - Core logic using Regular Expressions (RegEx) to handle input events and enforce rules.
